# application: ユースケース

業務ルールを組み合わせ、利用者が行う操作の順序を表す層です。現在は操作を実装しないため、コードは置きません。

- domainを利用できます。Next.js、Firebase SDK等の具体的な外部技術へ依存しません。
- 必要になった外部処理だけを小さなインターフェースとして定義します。実装はinfrastructure、生成と結線はcompositionが担当します。
- HTTPのRequest/ResponseやDBの行の形を、そのままユースケースの入出力にしません。
- ユースケースをテストするときは境界を差し替えます。汎用Repositoryや共通基底クラスは、必要性がない段階で作りません。
